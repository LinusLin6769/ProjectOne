# ProjectOne — Inbox
Drop any new idea, feedback, or complaint about ProjectOne here, in any format. Zero friction is the point — a single unpunctuated bullet is fine.
## How this works
1. Add an entry anytime, under `## New`. Date it if you can, but don't let that stop you from just writing it down.
2. Any session, at session-start (alongside `STATE.md`/`TASKS.md`), should also check `## New` here for anything unprocessed.
3. To process an entry: turn it into a `TASKS.md` item (or fold it into `STATE.md` if it's context rather than a task), then move the entry under `## Processed` with a one-line pointer to where it landed (task ID or commit hash).
4. Processed entries can be deleted once merged — git keeps the record, per `WARP.md`.
